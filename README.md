# krakenitmedia.com

Website for Kraken It' Media. Plain HTML/CSS, hosted on GitHub Pages.

- `index.html`: home page
- `knights-of-xyphos/index.html`: the game page
- `merch/index.html`: merch page (paste Shopify Buy Button code into each `<div class="buy">`)
- `assets/site.css`, `assets/site.js`: shared styles and script
- `assets/brand/`: studio logo and icons (placeholder pixel kraken)
- `assets/kox/`: Knights of Xyphos art
